# 万神赐财

面向手机浏览器的香港六合彩随机选号网页。HTML + CSS + 原生 JavaScript，无后端、无构建步骤。

## 使用

点击「请赐六数」随机生成 1–49 中的六个不重复号码；号码逐颗出现后升序排列。随后可「掷筊问财」，只有圣筊会出现「收下此签」，由使用者主动决定是否保存。

求财簿使用浏览器 localStorage 保存号码与确认时间，按时间倒序展示，支持删除单条记录。记录仅保存在当前浏览器中。

## 随机性

- 使用 `crypto.getRandomValues()` 与拒绝采样，消除取模偏差。
- 通过部分 Fisher–Yates 洗牌无放回抽取六数，每个六数集合等概率。
- 两个独立公平随机位决定筊面：圣筊 50%、笑筊 25%、阴筊 25%。
- 不预测开奖结果，不用历史记录、点香或敲木鱼影响随机结果。

支持减少动态效果系统偏好。筊杯浅色切面为平，深色圆背为凸。

## 文件与发布

- `index.html`：完整页面、内嵌样式与脚本。
- `assets/altar.webp`：本地神坛图片。
- `.nojekyll`：静态发布标记。
- `ASSET-NOTES.txt`：图片生成来源与提示词。

在 GitHub Pages 中使用 `main` 分支根目录发布即可。网站运行不需要 Node.js、数据库或任何付费服务。
